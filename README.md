QAgent 是企业智能体解决方案：把每个员工变成 AI 时代的「超级个体」，让企业把 AI 能力**安全、可见、可控**地变成自己的数字资产。

## 三个核心价值

从员工到企业，全面释放 AI 的生产力。

1. **随身 AI 助手** — 每个员工都拥有，极低使用门槛。起草邮件、整理会议纪要、解释代码、数据处理，像跟同事聊天一样自然，零门槛上手。
2. **企业级理解力** — 让 AI 真正理解您的企业。员工自己创作 AI 技能，把个人经验沉淀为企业能力：一次定好技能全员复用、新人也能产出专家水平、技能归企业所有人走能力留。
3. **自主掌控** — 从数据到技能资产全程自主掌控。私有化部署数据不出内网、权限管理、合规审计全程留痕、按席位订阅成本可控。

## 产品架构

- **QAgent Desktop（员工端）**：装在员工电脑上的桌面应用，开机即用。自然语言对话、长期记忆、工作区文件浏览、多模型切换、技能工作室、多会话管理、技能商店。
- **QAgent SaaS（企业管理端）**：一个 Web 控制台统一管理全公司的 AI 使用。企业管理、成员管理、订阅与席位、技能审核、使用概况、数据安全隔离、审计日志。

## 部署方式

| 方式 | 适合 | 特点 |
| --- | --- | --- |
| 公开 SaaS 版 | 中小企业、初创团队、快速试点 | 开箱即用，按席位按年付费，无需自建基础设施 |
| 私有定制版 | 国企、政府、金融、数据敏感型企业 | 部署在企业内网或私有云，数据全程不出域，含实施培训运维服务 |

> QAgent 不提供模型服务 — 企业可自主选择公有云模型（阿里云百炼 / 火山引擎 / 智谱 / DeepSeek）或部署私有模型，避免供应商锁定。

## 网站本地预览

纯静态站点，无需构建，直接打开 `index.html` 即可；也可以启动一个本地服务器：

```bash
npx serve .
# 或
python -m http.server 8080
```

默认简体中文，点击导航栏「EN」可切换为英文。
